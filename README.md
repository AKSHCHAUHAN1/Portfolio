## 📌 Overview

Welcome to the personal developer portfolio repository of **Aksh Chauhan**, a Computer Science undergraduate specializing in **DevOps & Cloud Systems** at UPES. This site highlights production-grade engineering projects, cloud infrastructure architectures, professional internship experiences, technical skill matrices, and a built-in interactive terminal experience.

Designed with an editorial-meets-cyberpunk aesthetic, it delivers responsive typography, fluid spring-based animations, view transitions for seamless light/dark mode switching, and enterprise-grade security headers.

## ✨ Key Features

- **🌐 Live Production Deployment:** Hosted and custom-domain mapped at **[akshchauhan.live](https://akshchauhan.live)** with automated build optimization and strict CDN caching policies.
- **🖥️ Interactive HUD Console & Terminal:** An integrated developer console accessible anywhere via the header (`TerminalSquare` button) or hotkeys. Type commands like `about`, `projects`, `experience`, `skills`, `education`, `contact`, or `resume` to query the site programmatically.
- **🌓 View Transitions & Theme Toggle:** Dark and light mode switching utilizing the modern CSS View Transitions API (`document.startViewTransition`) with dynamic radial clipping animations.
- **💼 Industry Experience:** Documented software engineering and DevOps internships at **Xebia IT Architects** and **Bhavyaa Enterprises Pvt. Ltd.**
- **🚀 Architectural Case Studies:** Detailed breakdown of distributed systems, telemetry engines, and cloud-native infrastructure with metrics, tech stacks, and repository links.
- **📊 Technical Skill Taxonomy:** Categorized proficiency across Cloud & Infrastructure, Full-Stack Web Development, Programming Languages, and Computer Science Fundamentals.
- **🔒 Enterprise Security Posture:** Pre-configured Content Security Policy (CSP), strict referrer policies, frame sandboxing (`DENY`), and permission policy headers across Vercel (`vercel.json`) and Netlify/Cloudflare (`public/_headers`).
- **📱 Fully Responsive & Accessible:** Built with semantic HTML5 elements, ARIA attributes, keyboard navigation traps for modals, reduced-motion preferences, and fast Core Web Vitals.

## 📦 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- `npm`, `yarn`, or `pnpm`

### Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AKSHCHAUHAN1/Portfolio.git
   cd Portfolio
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173` (or the URL displayed in your terminal).

4. **Lint and format checks:**
   ```bash
   npm run lint
   ```

---

## 🛠️ Production Build

Compile and bundle the production-ready assets into the `dist/` directory:

```bash
npm run build
```

To preview the production bundle locally:

```bash
npm run preview
```

The resulting assets in `dist/` are optimized, hashed, and ready for deployment to any static hosting provider (Vercel, Netlify, Cloudflare Pages, AWS S3/CloudFront, GitHub Pages).

## 🔒 Security & Deployment Posture

This site is statically generated and client-side executed:
- **No Private Credentials:** Contains no servers, databases, or private API secrets in client bundles.
- **Strict Content Security Policy (CSP):** Enforced via `vercel.json` and `public/_headers` to restrict script execution, block unauthorized framing (`frame-ancestors 'none'`), prevent MIME-type sniffing (`nosniff`), and control media origins.
- **HTTPS Only:** Production traffic must be served strictly over TLS/HTTPS with automated upgrades.
